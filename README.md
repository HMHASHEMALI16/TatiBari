# TatiBari
Tati Bari (তাঁতি বাড়ি) Omar Ali Saree House

## Updating the catalog
1. Put/rename photos in `D:\For website\D1 জামদানি` — names start with A–D + number (`A28.jpg`, `A28 (2).jpg`, `B23.png`). Same code = same saree (multiple photos).
2. Double-click `update-site.bat` (needs Python + Git). It optimises photos, rebuilds `products.json`, commits and pushes.
3. Edit `products.json` to set `name`, `tagline`, `price`, `soldOut` per saree — your edits are kept on the next update.
